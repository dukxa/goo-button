# Code of conduct

This project is open to issues, pull requests, and discussions. A few simple rules to keep it comfortable for everyone.

## What I expect

- Respect for other people, even when you disagree with their opinion or their code.
- Constructive criticism. Point out the problem and, if you can, suggest a fix.
- Patience. This is a one-person open source project, so a reply can take a while.

## What's not okay

- Insults, harassment, personal attacks.
- Discrimination of any kind: gender, race, religion, sexual orientation, experience level, and so on.
- Spam, ads, or links that have nothing to do with the issue or PR.
- Posting someone else's personal info without their consent.

## If something happens

Reach out directly. Use [GitHub Issues](https://github.com/dukxa/goo-button/issues) for public matters or the [author's profile](https://github.com/dukxa) for anything private.

I'll look into it and respond, from a warning up to a ban from the repo, depending on how serious it is.

## Scope

This applies to issues, pull requests, discussions, and any other communication inside this repository.
